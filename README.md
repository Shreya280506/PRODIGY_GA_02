# 🎨 VisionCraft AI

## AI-Powered Text-to-Image Generation using Stable Diffusion

VisionCraft AI is a Generative AI application that transforms **text prompts into AI-generated images** using the **Stable Diffusion** model.

The project combines a pre-trained diffusion model with an interactive **Streamlit web interface**, allowing users to enter creative prompts and generate images from natural language descriptions.

---

## ✨ Project Overview

Text-to-image generation is one of the most popular applications of Generative AI.

VisionCraft AI demonstrates how a diffusion-based generative model can interpret a natural-language prompt and transform it into a visual output.
